Getting Started Guide

Learn how to use the Mober OKR Scorecard in 5 minutes.

📈 Dashboard tab

At-a-glance view of your OKR health. Shows overall % on track, per-objective progress bars, and a full heatmap of all KRs across 13 weeks. Best for weekly reviews and exec presentations.

📋 Scorecard tab

The full 13-week RAG table. Click any cell to update status, enter actual values, and add notes. W6 is the Plan B gate — if 3+ KRs are red by W5, it triggers automatically.

📄 Audit Trail tab

Every cell change is logged — who changed it, from what to what, when, and any notes added. Pulls live from Supabase. Admins can also see the User Activity Log in Settings.

⚠ Plan B

Auto-triggers when 3+ Key Results are Red for 3+ weeks in W1–W5. W6 cells turn purple (P). A banner shows corrective actions per objective. Admin can adjust the threshold in Settings.

👤 Roles explained
🔐
Admin
Full access — update cells, add/edit/delete OBJs and KRs, manage users, configure settings
✎
Editor
Can update RAG cells, enter actuals and notes. Cannot change structure or manage users
👤
Viewer
Read-only. Can see the dashboard, scorecard and audit trail but cannot make any changes
🕑 Weekly rhythm
1
Every Monday — Editors update all RAG cells for the previous week. Enter actual values where possible.
2
Every week — Manager reviews Dashboard tab for trends, flags any yellows going red.
6
Week 6 — Plan B gate. If triggered, review corrective actions before proceeding to soft launch.
13
Week 13 — OKR cycle complete. Export CSV, back up JSON, reset cells for next cycle.
💡 Tips
  • Always enter the actual value when updating a cell — e.g. "42 accounts" not just G
  • Use Notes to explain yellows and reds — it shows in the audit trail
  • Download a Backup JSON before making structural changes to OBJs or KRs
  • The heatmap on the Dashboard tab is the fastest way to spot patterns across the quarter
  • New users must be approved by Admin before they can sign in
